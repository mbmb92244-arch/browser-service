# דפדפן מרוחק - מוטי דפדפנים בעם

שירות שמפעיל דפדפן Chromium על השרת ומזרים את המסך לגולש דרך דפדפן האינטרנט שלו.

## הרצה מקומית
    npm install
    npx playwright install chromium
    npm start
פתחו http://localhost:3000

## הרצה עם Docker (מומלץ לייצור)
    docker build -t remote-browser .
    docker run -p 3000:3000 --ipc=host remote-browser

## משתני סביבה
- PORT - פורט השרת (ברירת מחדל 3000)
- MAX_SESSIONS - מספר גולשים במקביל (ברירת מחדל 20). כל גולש מפעיל דפדפן מלא, כך שזה צורך זיכרון רב
- IDLE_MS - זמן חוסר פעילות לפני ניתוק (ברירת מחדל 5 דקות)

## חשוב לפני פרסום לציבור
- השירות חייב לעבור דרך HTTPS (wss://), כדי שההצפנה תהיה מלאה. השתמשו בפרוקסי כמו Nginx או Caddy עם תעודה.
- בדיקת הכתובות נעשית לפי DNS לפני הבקשה. תוקף שמשנה את הכתובת אחרי הבדיקה עלול לעקוף אותה. לייצור רציני מומלץ להוסיף בדיקה נוספת.
- לא נכללו הגבלת קצב לפי IP, לוגים, או מנגנון הרשמה. מומלץ להוסיף אותם.
- השירות עלול לשמש לעקיפת חסימות או לפעילות לא חוקית. בדקו את החוקים החלים עליכם.
- לא בדקנו את הקוד על שרת אמיתי. הריצו בדיקה לפני שימוש עם לקוחות.
